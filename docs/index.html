What is ion?

An early-stage C/C++ build system and future package manager, written in Rust.

Project layout

Config lives in .cbuild. Source in src/, headers in include/, output in build/.

Six core commands

init · build · run · check · env · clean

Getting Started

Prerequisites

  • A C/C++ compiler on your PATH (e.g. g++ or clang++).
  • The ion binary — grab it from Downloads or build from source with Rust.

Create a project

ion init .

Generates .cbuild/, src/, include/, build/, and a starter source file.

Build & run

ion build .
ion run . -- arg1 arg2

Profiles: --release, --debug, --fast.

Check & clean

ion check . --verbose
ion clean

check runs syntax checking. clean removes build/ and supports extension cleanup via --all --force.

Command Reference

init

ion init [path] [-c|-cpp] [--force] [--custom-structure=<path|clean>] [-i]

Scaffold a new project with .cbuild config and default directory structure.

build

ion build [target] [--profile] [-std N] [-opt N] [-I path]

Compile the target. Accepts --release, --debug, or --fast profiles.

run

ion run [target] [-in file] [-out file] [--profile] [-- args...]

Build then execute the binary. Env vars from .cbuild/env/run.env are injected automatically.

check

ion check [target] [--profile] [--verbose] [-std N]

Syntax-only compilation — catches errors without producing a binary.

env

ion env [--cmd run|build] [KEY=VALUE ...] [-path file] [--clear]

Manage environment variables stored in .cbuild/env/run.env or build.env.

clean

ion clean [--all --force] [.ext ...] [-e path]

Remove build/. With --all --force, also deletes files matching given extensions.
